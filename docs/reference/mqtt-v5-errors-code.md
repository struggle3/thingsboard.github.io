## MQTT v.5 错误码

下表列出 MQTT 5.0 错误码及其说明。这些错误码用于表示客户端与 ThingsBoard 平台通信期间可能出现的各种状态与错误。

| Error Code | Name                          | Packets                                               | 说明                                                                                                                                                                                                                                                                     |
|------------|-------------------------------|-------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 128        | Unspecified error             | CONNACK, PUBACK, PUBREC, SUBACK, UNSUBACK, DISCONNECT | 发生未指定错误。                                                                                                                                                                                                                                                          |
| 129        | Malformed Packet              | CONNACK, DISCONNECT                                   | 表示接收到的报文无法按协议规范正确解析。                                                                                                                                                                                                                                   |
| 130        | Protocol Error                | CONNACK, DISCONNECT                                   | 协议错误通常指在控制报文按协议规范解析后才能发现的错误，包括协议不允许的数据、不符合协议要求的行为等。                                                                                                                                                                     |
| 131        | Implementation specific error | CONNACK, PUBACK, PUBREC, SUBACK, UNSUBACK, DISCONNECT | 报文有效，但未被当前接收方实现接受。                                                                                                                                                                                                                                       |
| 132        | Unsupported Protocol Version  | CONNACK                                               | 请求的协议版本不被服务器支持。                                                                                                                                                                                                                                             |
| 133        | Client Identifier not valid   | CONNACK                                               | 仅用于 CONNACK 报文，表示 Client ID 格式有效但服务器不接受。例如 Client ID 超过服务器允许的最大长度。                                                                                                       |
| 134        | Bad User Name or Password     | CONNACK                                               | 仅用于 CONNACK 报文，表示因用户名或密码错误，客户端连接被拒绝。                                                                                                                                                                                                             |
| 135        | Not authorized                | CONNACK, PUBACK, PUBREC, SUBACK, UNSUBACK, DISCONNECT | 表示操作未授权。例如客户端无权限向对应主题发布消息。                                                                                                                                                                                                                        |
| 136        | Server unavailable            | CONNACK                                               | 仅用于 CONNACK 报文，告知客户端服务器当前不可用。                                                                                                                                                                                                                           |
| 143        | Topic Filter invalid          | PUBACK, PUBREC, DISCONNECT                            | Topic Filter 格式正确但服务器不接受。例如 Topic Filter 层级超过服务器允许的最大数量。                                                                                                                          |
| 144        | Topic Name invalid            | PUBACK, PUBREC, DISCONNECT                            | Topic Name 格式正确但客户端或服务器不接受。                                                                                                                                                                                                                               |
| 149        | Packet too large              | CONNACK, DISCONNECT                                   | 报文超过连接时约定的最大允许大小。                                                                                                                                                                                                                                         |
| 151        | Quota exceeded                | CONNACK, PUBACK, PUBREC, SUBACK, DISCONNECT           | 超出管理配置的限制。                                                                                                                                                                                                                                                       |
| 153        | Payload format invalid        | PUBACK, PUBREC, DISCONNECT                            | 表示 Payload 格式与 Payload Format Indicator 属性指示的格式不符。                                                                                                                                                                                                         |
| ---        | ---                           | ---                                                   | ---                                                                                                                                                                                                                                                                       |
