[**ThingsBoard Cloud**](/products/paas/) 是一款全托管、可扩展且高可用的物联网应用平台。
适合希望使用 [ThingsBoard](/docs/{{docsPrefix}}getting-started-guides/what-is-thingsboard/) 但不想自行托管平台实例的用户。
作为平台用户，您将获得 [租户账户](/docs/{{docsPrefix}}user-guide/entities-and-relations/)，其实体与 API [限制](/docs/{{docsPrefix}}user-guide/tenant-profiles/#entity-limits) 由 [订阅计划](/docs/{{docsPrefix}}subscription/) 决定。

使用 **ThingsBoard Cloud** 可享有以下优势：

- **高级功能**：平台支持全部 [Professional Edition](/products/thingsboard-pe/) 功能及高级 [域管理](/docs/{{docsPrefix}}domains/)。
- **更快上市**：节省平台维护与功能配置时间。
- **降低成本**：集群基础设施成本由平台用户共同分担。
- **高可用**：ThingsBoard Cloud 采用微服务架构，部署于多可用区。
- **数据持久化**：平台通过数据复制与备份流程确保数据不丢失。
