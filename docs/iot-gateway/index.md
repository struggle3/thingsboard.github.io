title: IoT Gateway
description: ThingsBoard IoT Gateway 用于将既有与传统 IoT 设备接入平台

---

ThingsBoard **IoT Gateway** 可将接入传统与第三方系统的设备与 ThingsBoard 物联网平台集成。

例如，可从接入外部 **MQTT broker**、**OPC-UA 服务器**、**Sigfox Backend**、**Modbus 从站**或 **CAN 节点**的设备中采集数据。
