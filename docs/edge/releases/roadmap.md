以下产品路线图仅涵盖**主要功能**，不包含次要增强与错误修复。

## v4.4.0

**重大**发布，包含 **ThingsBoard CE** 的所有功能，以及：
* ThingsBoard Runner - Docker 服务，可通过 ThingsBoard UI 一键在远程机器上安装和升级 Edge 实例及 IoT Gateway。
* Edge 首页 - 新区域，提供所有 Edge 实例的集中一览视图，包括统计、告警、连接状态和上行/下行速率。
