
以管理员身份启动 Windows 命令行（命令提示符），切换到 ThingsBoard Edge 安装目录。

执行 **install.bat** 脚本，将 ThingsBoard Edge 安装为 Windows 服务。
安装后系统启动时会自动运行。
同理，**uninstall.bat** 可将 ThingsBoard Edge 从 Windows 服务中移除。
输出应类似如下：

  ```text
C:\Program Files (x86)\tb-edge\install.bat
Detecting Java version installed.
CurrentVersion 110
Java 11 found!
Installing Thingsboard Edge...
...
ThingsBoard Edge installed successfully!
```
