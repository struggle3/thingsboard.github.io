
启动 **ThingsBoard Edge** 服务：
```bash
sudo service tb-edge start
```
{: .copy-code}

停止 **ThingsBoard Edge** 服务：
```bash
sudo service tb-edge stop
```
{: .copy-code}

重启 **ThingsBoard Edge** 服务：
```bash
sudo service tb-edge restart
```
{: .copy-code}

查看 **ThingsBoard Edge** 服务状态：
```bash
sudo service tb-edge status
```
{: .copy-code}
