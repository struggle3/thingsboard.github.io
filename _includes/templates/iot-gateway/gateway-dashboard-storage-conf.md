存储 - 提供在将传入数据发送到平台之前进行保存的配置：
- [内存存储](/docs/iot-gateway/configuration/?storageConfig=memory#storage-configuration) - 将数据保存到 RAM 内存。
- [文件存储](/docs/iot-gateway/configuration/?storageConfig=file#storage-configuration) - 将接收到的数据保存到硬盘。
- [SQLITE](/docs/iot-gateway/configuration/?storageConfig=sqlite#storage-configuration) - 将数据保存到 .db 文件。
