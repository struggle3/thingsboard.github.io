此 identity 小节选项最简单。

| **参数** | **默认值** | **说明**                    |
|:--------------|:------------------|------------------------------------|
| type          | **anonymous**     | OPC-UA 服务器上的 identity 类型。 |
| ---           |                   |                                    |

配置的此部分将如下所示：  

```json
    "identity": {
      "type": "anonymous"
    },
```
