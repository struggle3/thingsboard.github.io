#### Confluent Cloud 配置

要访问 [Confluent Cloud](https://docs.confluent.io/current/platform.html#what-is-cp)，您需要先创建[账户](https://confluent.cloud/login)，然后创建 [Kafka 集群](https://docs.confluent.io/current/quickstart/cloud-quickstart/index.html#step-1-create-a-ak-cluster-in-ccloud)并获取您的 [API Key](https://docs.confluent.io/current/quickstart/cloud-quickstart/index.html#step-4-create-an-api-key)。
