## Trendz Analytics v1.14.0（2025年11月6日）

**改进：**

* 添加 Metric Explorer 功能
* 添加 Native Calculation Fields
* 引入新视图类型：AI Card
* 支持使用多个 AI 模型
* 支持测试 Prompt
* AI Summary 模块支持 Markdown
* 支持 ARM 架构
* 支持非数值计算字段
* Python Executor 支持安装自定义库
* 外部数据源逻辑支持 MSSQL、MySQL、Oracle 数据库
* 通过优先处理 UI 请求于后台任务改进性能
* 改进异常模型 UI

**故障修复：**

* 修复平均聚合
* 修复 Prompt 与视图摘要任务逻辑
* 修复 Python 安全问题
* 修复状态字段逻辑
* 修复 tooltip 可见性问题
* 修复遥测发送后设备变为活跃状态的问题
