## Trendz Analytics v1.15.0（2026年1月20日）

**改进：**

* 实现 Trendz 与 ThingsBoard 之间的双向通信
* Trendz 与 ThingsBoard 通信从 JWT token 切换至 API token；移除签名密钥
* 实现 licensing 逻辑 v2
* 将 Trendz Widget Bundle 与 JS summary 模块迁移至系统管理员级
* 实现 Trendz Widget Bundle 与 JS summary 模块的自动更新
* 添加 Advanced Analytics View 部件，替代 Trendz View Static 与 Trendz View Latest 部件
* 统一 Trendz 更新脚本以匹配 ThingsBoard 风格
* 任务页添加更多信息
* 移除外部字体依赖
* 改进异常模型构建与刷新性能

**故障修复：**

* 修复异常模型重建功能
* 修复仪表板上水平图表布局渲染
* 修复 Mozilla Firefox 中的加载器重复问题
* 修复高负载下的冻结问题
* 解决所有严重与高危漏洞
