## Trendz Analytics v1.9.0（2022年2月2日）

**改进：**

* 添加可配置的填充缺口策略
* 添加视图模板
* 将计算指标保存为 ThingsBoard 遥测
* 支持报表中的 Alarm 字段
* 支持报表中的 Anomaly 字段
* 饼图中合并多个字段
* 保存状态与计算字段以供复用
* 实现多根关联项加载
* 状态与计算字段切换至 JavaScript 引擎
* 改进时序预测模型
* 支持 ThingsBoard 的区间时间窗口
* 改进大数据集性能
* 更新 ThingsBoard 3.3+ 原生库
* 报表内 filter 值自动刷新
* 更新资源路径以支持 Trendz 与 ThingsBoard 同域托管
* 柱状图/折线图可配置 tooltip 类型
* 报表构建期间采集指标
* 在 Trendz 服务内托管 ThingsBoard 部件库资源
