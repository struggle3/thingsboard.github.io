## Trendz Analytics v1.10.2（2023年8月18日）

**改进：**

* 计算字段支持 Python 脚本（Beta）
* 预测模型支持 Python 脚本（Beta）
* 支持多变量预测模型
* 添加新预测模型：Prophet、ARIMA、SARIMAX
* ThingsBoard 仪表板上部件支持实时自动刷新
* 添加白标设置
* 添加深色模式
* 支持手动设置坐标轴最小/最大范围

**故障修复：**

* 修复含特殊字符字段的发现流程
* 修复导出 PDF 时 Trendz 部件空白
* 修复计算字段的 delta 聚合
* 修复 Trendz 部件包更新至最新版本流程
