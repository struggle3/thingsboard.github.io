## Trendz Analytics v1.10.1（2023年5月10日）

**改进：**
* 支持定时触发异常自动发现
* 添加计算字段开发调试工具
* 将简单计算字段计算迁移至后端 JS 引擎
* 更新部件包至 ThingsBoard v3.5
* 计算字段支持预测
* 视图字段支持不区分大小写搜索
* 表格、饼图、柱状图添加 top-N 限制
* 计算字段支持 groupBy 输入参数
* Anomaly View 支持单独显示图表与表格
* 异常日历：添加全范围视图模式
* 图表标签与 tooltip 添加单位
* 添加用户详情菜单

**故障修复：**
* 登出时清除缓存存储
* 修复日历热力图的响应式布局
* 修复后台任务授权错误
* 修复 Anomaly 视图的模型变更
* 修复视图标题文字尺寸自动缩放
* 修复 URL 中 token 的认证
* 修复导出数据的时间格式化
* 修复图表选项编辑器的合并流程
* 修复部件的日期选择器定位
