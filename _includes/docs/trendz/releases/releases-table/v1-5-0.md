## Trendz Analytics v1.5.0（2020年8月11日）

**改进：**

* 添加白标选项
* 支持内置与自定义可视化主题
* 图表与热力图可配置调色板颜色
* 可配置字体大小
* 每个字段可独立设置小数位数
* 可配置可视化工具栏
* 表格支持显示/隐藏 Total 列
* 可调整图例位置
* 图表可配置线条样式
* 部件包：从 ThingsBoard 仪表板获取时间
* 部件包：通过 ThingsBoard 别名支持多值过滤
* 可配置坐标轴位置与标签

**故障修复：**

* 修复时区处理
* 移除嵌入式可视化的多余滚动
* 修复单序列空热力图/柱状图
* 修复拓扑重新发现流程
* 修复日期字段排序
