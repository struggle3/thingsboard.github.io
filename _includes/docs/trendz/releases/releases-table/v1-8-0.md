## Trendz Analytics v1.8.0（2021年8月27日）

**改进：**

* 为状态、简单字段与计算字段添加持久化缓存
* 添加视图报表短期缓存
* 支持字段缓存的定时刷新
* 为 ThingsBoard 添加原生部件包
* 将使用 canvas 的视图的渲染引擎更换
* 为第三方服务添加简化的 REST API
* 日历视图添加日期点击事件
* 表格添加行点击事件
* 开关配置添加字段变更事件
* 保存状态与计算字段配置
* 改进查询分区
* 改进异常加载时间
* 添加加载原始遥测而非分区加载的选项
* 为仪表板上的视图添加预览/编辑链接
* 添加在视图中将字段标记为隐藏的选项

**故障修复：**

* 表格：修复首字段非静态时的合计行
* 克隆异常检测模型时清除重复项
* 修复状态持续时间百分比计算
* 修复水平图表的区间格式化问题
* 修复无效 JWT token 存储
* 修复批量字段计算中的死锁
