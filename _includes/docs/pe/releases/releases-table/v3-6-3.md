### ThingsBoard PE v3.6.3（2024 年 3 月 18 日）

包含 [TB CE v3.6.3](https://github.com/thingsboard/thingsboard/releases/tag/v3.6.3) 的全部内容及以下改进与 Bug 修复。

**改进**

* Core & Rule Engine
  * WL 中新增“hide connectivity dialog”选项；
  * 支持启用/禁用 Scheduler 事件；
  * 更新 TbDuplicateMsgToGroupByNameNode；
  * 移除 3.5.0 之前版本的升级支持；
* UI
  * White labeling 高级 CSS 支持全局 CSS 变量；
  * OTA package 在设备组详情面板/页添加详情页链接；
  * 导出时支持禁用 cell content 函数；
  * 新增 Twilio 规则节点示例；
  * 为 saveDeviceWithAccessToken 添加 Transactional；
  * 文档链接添加平台前缀；
  * Scheduler 添加部分法语翻译；
  * 改进时序表部件的导出；
  * 改进 web report 错误处理并添加 debug 日志；
  * Scheduler 事件重新设计实现；
  * Scheduler 基础与 validator 重构；
  * Dashboard 表行点击现打开 dashboard；
* Edge
  * 支持 customMenu 实时更新；
  * 支持设备组 OTA package；
  * 客户级 entity group All 命名中添加客户名称；

**Bug 修复**

* Core & Rule Engine
  * 修复 GRPC Remote TCP/UDP 集成并发问题；
  * 修复 login white labeling 设置合并；
  * 修复 js-executor、rule-node 与 tb-rule-engine-notifications-node 的 consumer group id 的全局队列前缀；
  * 修复 IN、NOT_IN 类型操作的告警状态处理；
  * 修复邮件设置使用 OAuth2 时的 useSystemMailSettings 处理；
  * 修复子客户的自定义翻译继承；
  * 修复 TbAwsSqsProducerTemplate；
  * Swagger 中排除 http 集成 api；
* UI
  * 修复更改值类型不影响校验组件；
  * 修复 WL 的平台名称与版本位置不显示默认值；
  * 油位监控 bug 修复与改进；
