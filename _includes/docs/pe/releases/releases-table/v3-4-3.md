### ThingsBoard PE v3.4.3（2022 年 12 月 21 日）

包含 [TB CE v3.4.3](https://github.com/thingsboard/thingsboard/releases/tag/v3.4.3) 的全部内容及以下改进与 Bug 修复。

* Core & Rule Engine：
  * 空气质量监控 Solution template；

* UI：
  * MQTT 集成凭据密码改为可选；

**Bug 修复**

* Core & Rule Engine：
  * 修复空凭据的设备批量导入；
  * 修复从 CE 升级；
  * 修复 Remote integration 更新；
  * 修复 sysadmin WS 订阅的 NPE；

* UI：
  * 修复 Things Park 集成校验；
  * 修复批量导入校验及 Edge 批量导入改进；
  * 修复 Scheduler 更新配置；
  * 修复 Azure IoT Hub 集成校验；

* Edge：
  * 修复 Edge owner 为客户时同步过程中的 NPE；
