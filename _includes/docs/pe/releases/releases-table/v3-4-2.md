### ThingsBoard PE v3.4.2（2022 年 12 月 1 日）

包含 [TB CE v3.4.2](https://github.com/thingsboard/thingsboard/releases/tag/v3.4.2) 的全部内容及以下改进与 Bug 修复。

* Core：
  * WhiteLabeling、LoginWhiteLabeling 与 CustomTranslation 实时同步至 Edge；
  * 智能灌溉 Solution template；
  * 通过 Prometheus 进行集成监控；
  * 改进“alarms count v2”规则节点；
  * BLOB 实体的分区与 TTL；

* UI：
  * 改进集成 UI 设计：集成表添加创建对话框、统计与状态；

**Bug 修复**

* Core：
  * [#7415](https://github.com/thingsboard/thingsboard/issues/7415) 修复 Entity Group Name 筛选器；
  * [#7225](https://github.com/thingsboard/thingsboard/issues/7225) 修复 Scheduler 时区间隙；
  * 修复 Scheduler“Start time”错误；
  * 修复二进制 uplink 数据 converter；
  * 修复 WL 设置覆盖问题；

* UI：
  * 修复 TTN/TTI 集成 host 字段值显示；
