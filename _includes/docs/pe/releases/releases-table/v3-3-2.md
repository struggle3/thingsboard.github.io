### ThingsBoard PE v3.3.2（2021 年 11 月 11 日）

包含 [TB CE v3.3.2](https://github.com/thingsboard/thingsboard/releases/tag/v3.3.2) 的全部内容及以下改进。

主要功能：

* Core：
  * 系统管理员的实体搜索 API；
* REST API 文档：
  * 描述 PE 实体与方法；
* 用户自定义 JS 函数帮助页：
  * Uplink 与 Downlink converter 文档；
  * 支持通过 white-labeling 参数配置外部帮助 URL；
* Rule Engine：
  * 在 customer details 节点中支持获取父客户详情；
  * 使用外部邮件发送方时忽略 emails api 使用量；
* UI：
  * 自助注册添加“Terms Of Use”；
  * 支持为登录页设置背景；
  * 增加 Role、Integration、Converter、Group 与 Scheduler 最大长度校验；
  * Api Usage dashboard 中支持禁用导出（用于通知）；
* Integrations：
  * HTTP/CoAP/MQTT 集成支持二进制数据消费；
  * UDP 集成改进，HTTP/CoAP 集成支持 PUT；
  * 支持设备与资产标签；
  * 优化错误日志；

Bug 修复：

* Core：
  * 修复 Resource 与 OTA 更新的 RBAC；
* Integrations：
  * Service bus Queue：maxMessages 修复；
  * 修复 LORIOT 集成保存后 Downlink URL 显示错误；
* UI：
  * 修复创建/写入 edge 的 RBAC；
  * 修复 entity-group-autocomplete；
  * 修复自定义 CSS 对话框关闭按钮；
  * 修复更新 entity group 后 customersHierarchy 未在 jsTree 中保存新设置组；
  * 修复 scheduler/blob 部件中的 noDataDisplayMessage；
  * 修复 Relations 与 Permissions 选项卡上 RBAC 禁用 select；
  * 修复 rule chain 详情选项卡的 RBAC；
  * 修复更新 icon 包后的缺失图标；
  * Edge Downlinks 表小修复；
