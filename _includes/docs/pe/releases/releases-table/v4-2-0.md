### ThingsBoard PE v4.2.0（2025 年 8 月 15 日）

包含 [TB CE v4.2](https://github.com/thingsboard/thingsboard/releases/tag/v4.2) 的全部内容及以下改进与 Bug 修复。

**改进**

* Core & Rule Engine
  * Report service 2.0，支持丰富 PDF 与 CSV 能力；
  * Version Control、SMS、Mail server、OAuth 与 AI 模型设置支持 Secrets 存储；
  * Scheduler 事件的 Version control 支持与搜索改进；
  * 租户设置从 attributes 迁移至 admin settings 表；

* UI
  * Scheduler 事件分页与搜索；
  * 支持单个 Scheduler 事件的 Version control；

* Edge
  * 增加 Secrets Storage 支持；

**Bug 修复**

  * 修复带懒加载内容的部件的 web report 生成；
  * 修复 Scheduler 日历事件显示；
  * 修复 TCP 二进制集成表单的布局问题；
  * 修复 LORIOT 与 Particle 集成的凭据校验；
  * 修复生成的 Scheduler 事件配置；
  * 修复集群部署中的 OAuth 2 邮件认证问题；
  * 修复 Profile 与 Notification 设置中 UI 交互的权限检查；
