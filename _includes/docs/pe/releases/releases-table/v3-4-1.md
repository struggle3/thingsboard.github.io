### ThingsBoard PE v3.4.1（2022 年 8 月 18 日）

包含 [TB CE v3.4.1](https://github.com/thingsboard/thingsboard/releases/tag/v3.4.1) 的全部内容及以下改进与 Bug 修复。

* Core：
  * 修复 OPC-UA 集成的启动问题与连接泄漏；
  * 修复 Azure IoT Hub 集成；
* UI：
  * 2FA 登录表单支持 Login WL 高级 CSS；
  * 修复筛选；
  * 修复 entity group 自动补全；
  * 升级 ExcelJS 并修复空单元格样式；
* Web Report：
  * 生成 web-report 前添加部件缓存清理；
  * 修复部件状态更新时的报表生成问题；
