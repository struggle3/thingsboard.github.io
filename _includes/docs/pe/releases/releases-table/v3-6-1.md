### ThingsBoard PE v3.6.1（2023 年 11 月 13 日）

包含 [TB CE v3.6.1](https://github.com/thingsboard/thingsboard/releases/tag/v3.6.1) 的全部内容及以下改进与 Bug 修复。

**改进**

 * Transport API 性能改进；
 * 支持通过 REST API 将 WL 从租户更新至客户；

**Bug 修复**

 * 修复 add edge 对话框；
 * 修复 converter 组件 debug mode 滑块常开；
 * 修复 Smart Irrigation 模板；
 * 修复收件人对话框标题错误；
 * 修复 Apache Pulsar 与 Tuya 集成中的 Apache Pulsar 客户端问题；
