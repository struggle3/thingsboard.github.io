### ThingsBoard PE v4.1.0（2025 年 7 月 3 日）

包含 [TB CE v4.1](https://github.com/thingsboard/thingsboard/releases/tag/v4.1) 的全部内容及以下改进与 Bug 修复。

**改进**

* Core & Rule Engine
  * 支持使用 Calculated Fields 重新处理历史数据；
  * 新增 Calculated Field 参数来源：current owner；
  * Secrets 存储；
  * 长任务管理器；

* UI
  * 支持从 converters library 导入 data converter；
  * 改进翻译映射编辑器的布局格式；
  * Value stepper 与 Two-segment button 部件增加调色板；
  * 集成增加 MQTT 版本选择；

**Bug 修复**

* 修复保存自定义翻译的请求；
* 修复 Schedule events/blob entity 表的分页显示；
* 更新 web report 依赖；
