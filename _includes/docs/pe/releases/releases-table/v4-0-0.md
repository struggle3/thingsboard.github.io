### ThingsBoard PE v4.0.0（2025 年 4 月 15 日）

包含 [TB CE v4.0](https://github.com/thingsboard/thingsboard/releases/tag/v4.0) 的全部内容及以下改进与 Bug 修复。

**改进**

* Core & Rule Engine
  * 为特定集成类型设计的 Typed uplink data converter；
  * 改进聚合规则节点性能；
  * 改进 converter library 中的厂商与型号选择；
  * 通过 parallel 请求 Redis 缓存改进 Integration Executor 性能；

* UI
  * SCADA：石油天然气钻井系统 Solution template；
  * SCADA：能源管理 Solution template；
  * Solution templates 卡片重新设计；
  * Data converters 表添加 debug 配置选项；
  * Alias 配置中添加 Scheduler 事件类型自动补全；
  * Gauge 部件基本设置添加数据导出选项；
  * 移动注册添加 home dashboard 处理；
  * 更改 Scheduler 事件排序；
  * 自助注册表单现要求 Captcha 版本；

* Edge
  * Edge 连接时避免创建不必要的公开客户；

**Bug 修复**

* 修复客户详情 dashboard 自动补全；
* 修复 converter library 小描述时箭头按钮位置；
* 修复 converter library 型号搜索；
* 修复 entities 表内容导出；
* 修复邮件模板设置帮助链接；
* 修复 group actions 中自定义操作的帮助容器大小错误；
* 修复 Azure Event Hub 中 IoT Hub 名称输入位置；
* 修复 ThingPark 与 ThingParkEnterprise 的 converter library；
* 修复 entity 数据查询 bug；
* 修复使用 dedicated events datasource 时的集成每日活动统计；
* 修复 OTA 删除后 group 的关系清理；
* 修复 timeseries 表导出 latest 数据；
* 修复登录页未翻译错误信息；
* 禁止通过 API 更改 converter 类型；
