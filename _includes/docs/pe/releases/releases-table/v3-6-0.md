### ThingsBoard PE v3.6.0（2023 年 9 月 21 日）

包含 [TB CE v3.6](https://github.com/thingsboard/thingsboard/releases/tag/v3.6) 的全部内容及以下改进与 Bug 修复。

**改进**

* Core & Rule Engine
  * 为多数具有明确定义消息格式的集成提供默认 converter；
  * 油位监控 Solution template；
  * 将集成速率限制配置移至 tenant profile；
  * 改进 group 权限、group owner 与资源删除的校验；
  * 将 white labeling 属性从 attributes_kv 移至 white_labeling 表；

* UI
  * 时序数据删除 UI；
  * 基于域名的 White labeling 登录 base URL 自动生成；
  * Integration 向导布局；

* Transport
  * 新增 Efento 设备新消息类型处理；

* Edge
  * Edge 安装说明小幅更新；

**Bug 修复**

* Core & Rule Engine：
  * 修复 TCP/UDP 集成二进制 payload；
  * 修复 msa 中的 rabbitmq 队列；
  * 修复 dashboard 中的写权限检查；
  * 修复获取属性与时序 keys；
  * 修复自定义菜单层级；
  * 修复使用 GroupList 筛选器的 entityDataQuery；
  * 修复 MQTT 集成 ClientID 字段校验；

* UI：
  * 修复 dashboard 全屏按钮；
  * 修复创建时 Scheduler 事件开始时间的初始值；
  * 修复 group entities 表 excessive API 调用；
  * 修复 Firefox 中自定义翻译与菜单 json 内容占位符单行显示；
  * 修复通知中心租户管理员收件人筛选器；
  * 修复 Web report 中当 dashboard 有部件在桌面模式选择隐藏时的错误计数部件；
  * 修复客户用户排序；
