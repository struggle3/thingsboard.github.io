### ThingsBoard PE v3.9.0（2024 年 12 月 31 日）

包含 [TB CE v3.9](https://github.com/thingsboard/thingsboard/releases/tag/v3.9) 的全部内容及以下改进与 Bug 修复。

**改进**

* Core & Rule Engine
  * 通知本地化；
  * 更新默认 converter；
  * 自助注册通知迁移至通知中心；
  * 跨所有相关实体的租户域名统一存储；
  * BLOB 实体的 Housekeeper TTL 清理实现；
  * Integrations 与 Converters 的高级 debug mode 设置；

* UI
  * 改进帮助链接生成；
  * Converters 表增加 description 列；
  * 支持将 white labeling 重置为默认；
  * 自定义菜单添加新子项时自动向下滚动；
  * 更新 Water Metering Solution template 的导航按钮；

**Bug 修复**

* 修复 entity hierarchy 部件未显示 entity groups；
* 修复每租户的集成速率限制；
* 修复油位监控模板；
* 修复将 entity group 设为私有时的错误；
* 修复自定义翻译中复制按钮显示错误（Firefox）；
* 修复重新发送激活邮件时的用户激活链接刷新；
* 修复 entitiesByGroupNameFilter 在 ownerId 非空时；
* 修复无 dashboard group 权限时打开默认 dashboard；
* 修复先前创建的自定义菜单中缺失新菜单项；
* 修复邮件模板与自助注册编辑器配置；
* 修复登录 white labeling 中更新的 base URL；
* 修复 persist 集成统计时的 NPE；
* 修复 converter library 中的厂商 logo 显示；
* 修复 version control 导入 entity groups 的问题；
* Solution template 自定义操作拼写修复；
