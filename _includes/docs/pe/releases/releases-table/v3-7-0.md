### ThingsBoard PE v3.7.0（2024 年 6 月 17 日）

包含 [TB CE v3.7](https://github.com/thingsboard/thingsboard/releases/tag/v3.7) 的全部内容及以下改进与 Bug 修复。

**改进**

  * 高级本地化支持；
  * 用户组中租户管理员删除时增加校验；
  * owner 变更时增加最后管理员删除检查；
  * 新增 env 变量 USE_NEW_PAGE_FOR_REPORT；
  * “Duplicate to group”节点：支持使用 pattern 传递 entity group 名称；
  * “Change originator”与“Customer attributes”节点：支持在 originator 为客户时返回父客户 id；

**Bug 修复**

  * 修复客户级实体计数计算；
  * 修复 group 权限用户组变更时的权限缓存更新；
  * 修复 Integration Executor 的 Redis 配置；
  * 修复 Smart Irrigation 模板安装时的“Too many updates!”错误；
  * 修复系统邮件模板使用；
  * 修复 sysadmin 页面的滚动问题；
  * 修复 value card 的 XLSX 导出；
  * 修复 White labeling 页面长文件名的布局；
  * 禁用当前用户的“Login as”按钮；
  * 修复 Entity table 部件导出中因 Cell Content Function 中 Date() 导致的无效数据问题；
