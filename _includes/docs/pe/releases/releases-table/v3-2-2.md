### ThingsBoard PE v3.2.2（2021 年 3 月 24 日）

包含 [TB CE v3.2.2](https://github.com/thingsboard/thingsboard/releases/tag/v3.2.2) 的全部内容及以下改进。

主要功能：

* 更新自定义菜单：引入 dashboardId 参数以嵌入 dashboard，替代 iframe；
* Azure Event Hub Integration 已更新为新 SDK；
* 新增 ["Alarms Count Node"](/docs/pe/user-guide/rule-engine-2-0/analytics-nodes/#alarms-count-node) 新版本；
* 新增“Duplicate to group entities”；
* 在“Aggregate stream node”中支持按消息聚合数据；
* 在“Aggregate stream node”中支持按周（周日至周六）聚合数据；
* 扩展实体与告警表 CSV 导出的列导出参数；
* 集群模式下 Scheduler 与 Integration 服务改进；

Bug 修复：

* 安全：客户无法通过 Entity Query API 查看 Tenant 属性；
* 修复 Customer 将 Owner 从 Sub-Customer 改为 Customer；
* Sigfox 集成修复；
* 修复 Kafka 集成配置校验；
* 修复 TCP/UDP 集成的 downlink；
* 修复 IoT Hub 节点中的 SAS 凭据；
* OPC-UA 集成：跳过递归 tag 扫描，扫描结束显式断开；
* 若角色已在用，无法更改角色类型（Generic vs Group）；
* 修复 tb-web-report docker 镜像；
* UI：修复 LORIOT 集成中的凭据校验；
* UI：修复 entities；
