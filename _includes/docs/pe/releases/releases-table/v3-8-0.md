### ThingsBoard PE v3.8.0（2024 年 10 月 3 日）

包含 [TB CE v3.8](https://github.com/thingsboard/thingsboard/releases/tag/v3.8) 的全部内容及以下改进与 Bug 修复。

**改进**

* Core & Rule Engine
  * 改进 findByTenantsIdsAndRoleId 的查询性能（通知系统）；
  * 增加 domain 与 base URL 校验；
  * 添加 Data converter library；
  * 为 entity group 服务添加缓存；
  * “Change Owner”节点重构；

* UI
  * 实体组“On row click”操作提示；
  * 更改实体组“Copy Entity Id to buffer”自定义操作函数示例；
  * 为网页 crash 与 close 事件添加错误处理，改进 WebReport 组件日志；
  * 支持通过 converter library 为特定设备选择 converter；

**Bug 修复**

  * 修复 group entities 表“navigate to other dashboard”操作“open in a new browser tab”选项无效；
  * 修复 WL 禁用时打开用户 profile 的权限拒绝；
  * 修复租户/客户设置 base url 时无 http schema 的 deeplink 获取；
  * 修复 ChirpStack、LORIOT、TTN 与 TTI 集成的默认 uplink converter；
  * 修复 Twilio voice 节点中的 NoClassDefFoundError；
  * 修复 getEntityGroupPermissions；
  * 修复 Scheduler 日周 short labels 拼写错误；
  * 修复登录 WL baseURL 在保存后自动生成而非显示服务器上已保存 URL 的问题；
  * 修复 KPN icon 集成的颜色并优化该图标；
  * 修复 Kinesis 集成；
  * 修复 Remote integration 保存事件时的 NPE；
  * 修复 Waste Management 与 Assisted Living Solution template 的移动 dashboard 配置；
  * 移除静态部件的“enable data export”选项；
  * 对无权限的客户或用户隐藏 mobile qr code 部件的配置提示按钮；
