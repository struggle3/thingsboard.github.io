### ThingsBoard PE v3.2.1（2021 年 1 月 26 日）

包含 [TB CE v3.2.1](https://github.com/thingsboard/thingsboard/releases/tag/v3.2.1) 的全部内容及以下改进。

主要功能：

* Google Cloud Pub/Sub 集成；
* ChirpStack 集成；
* 向 Rule Engine 与审计日志发送“Owner changed”事件；
* UI：优化 ExcelJS 模块加载；

Bug 修复：

* 修复“aggregate stream”规则节点；
* 修复 AWS SQS 集成的关闭流程；
* 修复 tcp 集成中的 double uplink 转换；
* Remote integration：将参数“PRC_HOST”改为“RPC_HOST”；
* UI：修复单空格时误删 integration 参数；
* UI：修复 Chrome 浏览器中复制 integration 参数的问题；
* UI：修复 integration 与 converter 视图；
