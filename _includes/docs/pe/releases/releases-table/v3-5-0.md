### ThingsBoard PE v3.5.0（2023 年 5 月 9 日）

包含 [TB CE v3.5](https://github.com/thingsboard/thingsboard/releases/tag/v3.5) 的全部内容及以下功能与 Bug 修复。

**改进**

* Core & Rule Engine
  * Azure Service Bus 集成；
  * Tuya 集成；
  * 支持在 DEVICE 与 DATA CONVERTER 之间创建关系；

* UI
  * 新 Solution template“Waste Monitoring”；
  * 支持新菜单与实体表；

* Edge
  * Solution templates 的 Edge 计算支持；

**Bug 修复**

* 修复客户级 relation 查询；
* 修复禁用 integration 重启后的错误泛滥；
* 修复 Solution template 实体删除；
* 修复 Solution template Scheduler 事件创建；
* 修复 asset_profile 的列 key 映射；
* 修复 entity views 搜索；
* 修复 OPC 集成的 host 配置；
* 修复 Aggregate Latest 节点中 doCalculate 失败时的无输出消息问题；
* 修复设备批量导入时的遥测/属性更新；
* 修复 Azure IoT Hub 集成的凭据校验错误；
