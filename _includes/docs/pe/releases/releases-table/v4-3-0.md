### ThingsBoard PE v4.3.0（2026 年 1 月 20 日）

包含 [TB CE v4.3](https://github.com/thingsboard/thingsboard/releases/tag/v4.3) 的全部内容及以下改进与 Bug 修复。

**主要改进**

  * 新许可模型与 add-on 支持；

**次要改进**

  * 自定义菜单支持自定义图标；
  * Scheduler 事件页增加“Schedule”列；
  * OPC-UA 集成增加 endpoint 字段；
  * Edge Report 模板与 Scheduler 事件同步；
  * Line chart 报表组件改进；
  * 自定义菜单新增“user groups”指派人类型；
  * 禁止删除当前用户的 group；

**Bug 修复**

  * 修复将设备分配到另一租户后的过时 owners 缓存；
  * 修复报表中带“values”列的表渲染；
  * 修复 EDQS 下报表与报表模板不显示；
  * 修复报表文件名缺失扩展名；
  * 修复 Entities Table 部件“On cell click”操作的列顺序；
  * 修复 Timeseries Table 导出使用 entity label 而非 name；
  * 修复 Advanced Feature Schedule 列中的 Line break 显示；
  * 修复 timeseries 表 XLSX 导出的 timestamp 列格式化；
  * 修复导出表部件数据的列顺序；
  * 修复首次尝试保存报表详情后的错误；
  * 修复 Activation Link Expired 页面的颜色调整；
  * 修复集成 converter library 自动补全；
  * 修复 Edge PE 的安装与升级配置；
