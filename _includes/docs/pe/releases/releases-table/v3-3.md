### ThingsBoard PE v3.3（2021 年 8 月 13 日）

包含 [TB CE v3.3](https://github.com/thingsboard/thingsboard/releases/tag/v3.3) 的全部内容及以下改进。

主要功能：

* 改进 MQTT 集成性能；
* 改进 ChirpStack 集成校验，application server url 与 API token 现为必填；
* 支持 DTLS 模式的 CoAP 集成；
* 保存设备组时的确认对话框；
* 支持为 Azure Event Hub 指定 Consumer Group；
* 从 integration 向 Rule Engine 推送事件时使用设备 profile 中的队列；
* 改进 owner 自动补全组件；

Bug 修复：

* 客户在 dashboard 中无法查看子客户的部分数据；
* MQTT 集成：增加 max 设置字段；
* Remote integration 的 TLS 连接；
* 用户在编辑模式激活/未激活时资产菜单异常；
* 设备组中的 Manage credentials 按钮；
* Scheduler 部件处理自定义事件配置时的表现；
* Scheduler 服务对 repartition 事件的处理；
* OPC-UA 集成 downlink 及未连接状态下的更多日志；
