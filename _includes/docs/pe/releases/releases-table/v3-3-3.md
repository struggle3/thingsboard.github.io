### ThingsBoard PE v3.3.3（2022 年 1 月 27 日）

包含 [TB CE v3.3.3](https://github.com/thingsboard/thingsboard/releases/tag/v3.3.3) 的全部内容及以下改进。

主要功能：

* Core & Rule Engine：
  * 为 Alarm Count 规则节点添加“Propagation Entity Types”参数；
  * 为聚合规则节点添加“Queue Name”参数；
  * 将 REST_API_RULE_ENGINE_CALL 加入审计日志；
  * 告警读取权限的额外校验；
* UI：
  * 实体详情页支持；
  * Scheduler 事件页的持久页面链接；
  * White-labeling 的 CSS 变量支持；
  * 租户管理员可忽略系统级 White-labeling 设置；
  * 组名最大长度校验；
  * 自助注册表单的“Delete”按钮；
* Integrations：
  * Remote integration 的额外自动测试；
  * LORIOT 集成支持自定义域名；
  * TTI 集成的 API Version；
* 构建脚本：
  * ARM64 的 Docker 镜像检查；
  * K8S 脚本移至独立仓库；
  * 修正 Log4j → Slf4j 注解拼写；
* Edge：
  * 为 assigned-to-edge/unassigned-from-edge 添加缺失标签；
  * Edge 归属变更时向 Edge session 发送通知事件；
  * 改进集成测试；

Bug 修复：

* Core & Rule Engine：
  *  deprecated 告警计数查询修复；
  * 修复从 integration downlink 规则节点发送 RPC 响应；
  * 在 rest api call reply 方法中使用正确 service id 向正确服务发送消息；
* Integrations：
  * 修复 OPC UA 集成的重连；
  * 更新 converter 详情自动补全；
* UI：
  * 自助注册表单多处修复；
  * 修复使用空格而非名称创建实体组；
  * 修复非全屏模式下默认 dashboard 的编辑按钮显示；
  * 修复创建/更新/删除权限后关闭详情；
  * 修复 Device Profile 的审计日志显示；
