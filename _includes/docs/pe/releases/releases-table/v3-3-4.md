### ThingsBoard PE v3.3.4（2022 年 3 月 11 日）

包含 [TB CE v3.3.4](https://github.com/thingsboard/thingsboard/releases/tag/v3.3.4) 的全部内容及以下改进与 Bug 修复。

**Bug 修复**

* Core & Rule Engine：
  * RPC 请求触发中缺少 Origin Service ID；
  * Jenkins 仓库 URL 修复；
* UI：
  * 修复 Scheduler 对话框；
  * 修复从本地 HTTP 集成切换至 Remote HTTP 集成；
  * 修复 originator 选择组件的校验及 entity group 加载流程；
* Integrations：
  * 从 Remote integration 移除 Redis 依赖；
  * PE Kafka 集成针对 KAFKA-4090 的变通方案；
  * OPC-UA 重新扫描与重连的热修复；
* 构建脚本：
  * 因 tb-web-report 包兼容性限制，将 tb-pe docker 镜像限制为 linux/amd64 平台；
