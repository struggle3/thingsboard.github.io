### ThingsBoard PE v4.0.2（2025 年 7 月 3 日）

包含 [TB CE v4.0.2](https://github.com/thingsboard/thingsboard/releases/tag/v4.0.2) 的全部内容及以下 Bug 修复。

**改进与 Bug 修复**

* Converter library 中厂商与型号图片改为 Base64 编码替代 GitHub URL；
* 修复 OPC-UA 集成配置表单与 add integration 对话框的样式；
* 修复 TCP 集成在无变更时“Apply changes”按钮仍可点击的问题；
* 修复慢网络上添加 data converter 的问题；
* 修复 twilio 规则节点中的 configDirective；
