### ThingsBoard PE v4.2.1（2025 年 10 月 15 日）

**改进**

* Reporting：新 Chart 组件；
* Reporting：新 Split View 容器组件；
* Reporting：报表渲染与 dashboard 导出的多语言支持；
* Tuya 集成增加 AES GCM 加密方法支持；

* Reporting：修复报表时间快捷区间 Week (Sun-Sat)；
* Reporting：修复带 timeseries 数据的组件渲染；
* Reporting：修复 dashboard 组件编码；
* Reporting：修复报表模板中的文档链接；
* Reporting：修复 angle brackets 中 heading 不显示内容；
* Reporting：修复 timeseries 表组件 null 值的后处理函数；
* Reporting：修复带聚合与 originator 的 csv 表渲染；
* Reporting：修复“values”列名不支持的问题；
* 将 Azure SDK BOM 版本从 1.2.22 升级至 1.2.33 以修复与 GitHub Models 的集成；
