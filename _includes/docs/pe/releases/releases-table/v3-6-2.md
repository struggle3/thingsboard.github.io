### ThingsBoard PE v3.6.2（2023 年 12 月 28 日）

包含 [TB CE v3.6.2](https://github.com/thingsboard/thingsboard/releases/tag/v3.6.2) 的全部内容及以下改进与 Bug 修复。

**改进**

 * 若用户对 dashboard 有“Read”权限，则自动为部件授予“Read”权限；
 * 更新 sendRpcRequest Scheduler 事件配置，新增参数：is_one_way、persistent 与 timeout；
 * 油位监控 dashboard 增强；

**Bug 修复**

 * 域名现始终为小写；
 * Dashboard 报表生成错误处理；
 * 修复 OTA Package 实体的客户权限校验；
 * 修复“Count Unique”聚合节点从 DB 的初始化；
 * 修复邮件设置表单中邮件提供商的切换；
 * 修复 entity-group-autocomplete 组件；
 * 修复带文件名的部件数据导出自定义翻译；
 * 修复 Smart Retail Solution template 中的 dashboard 链接；
 * 修复 color-picker 无法选择已选颜色的问题；
