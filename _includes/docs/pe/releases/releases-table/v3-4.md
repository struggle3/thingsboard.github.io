### ThingsBoard PE v3.4（2022 年 7 月 19 日）

包含 [TB CE v3.4](https://github.com/thingsboard/thingsboard/releases/tag/v3.4) 的全部内容及以下改进与 Bug 修复。

**主要改进：**

* Core & Rule Engine：
  * Integration Executor——可扩展微服务，托管所有集成并与核心服务分离；
  * Entity Groups 的 Version Control 支持；
  * Aggregate stream 节点处理大数和小数；
* UI：
  * Web report 与 UI 性能改进；
* Edge：
  * 集成与 converter 支持；

**Bug 修复**

* Core & Rule Engine：
  * 修复 TbSimpleAggMsgNode 中的 NPE；
  * 修复夏令时调整时的 Scheduler 每日重复；
  * 正确处理 Twilio API 异常；
* UI：
  * 自定义翻译加载与更新；
  * “open dashboard”部件操作中的错误路由；
  * 属性更新时的 Scheduler 错误信息；
  * 删除 downlink converter 时检查引用集成；
