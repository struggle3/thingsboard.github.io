### ThingsBoard PE v3.3.1（2021 年 9 月 3 日）

包含 [TB CE v3.3.1](https://github.com/thingsboard/thingsboard/releases/tag/v3.3.1) 的全部内容及以下改进。

主要功能：

* 引入 [Solution templates](/docs/pe/solution-templates/overview/)；
* UI：新增 Rule Engine 服务，支持从自定义操作调用 Rule Engine；
* Remote integration：支持在无服务器 SSL 证书时配置 RPC SSL；

Bug 修复：

* UI：修复权限资源自动补全中的缓存数据错误；
* UI：修复 **The Things Stack Industries** 集成表单；
