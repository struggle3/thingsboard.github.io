包含 [TB CE v4.0.1](https://github.com/thingsboard/thingsboard/releases/tag/v4.0.1) 的全部内容及以下 Bug 修复。

**Bug 修复**

* 修复自助注册中“+”的邮件问题并改进用户激活流程；
* 修复 Data Converter 2.0 测试对话框中的 raw payload 更新；
* 修复 Data Converter 中更改脚本语言时将函数内容重置为默认的问题；
