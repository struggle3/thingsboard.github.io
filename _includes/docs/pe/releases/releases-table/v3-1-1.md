### ThingsBoard PE v3.1.1（2020 年 8 月 28 日）

包含 [TB CE v3.1.1](https://github.com/thingsboard/thingsboard/releases/tag/v3.1.1) 的全部内容及以下改进。

主要功能：

* 新增 Apache Pulsar 集成；
* 为 converter 添加生命周期事件“UPDATE”；

Bug 修复：

* UI：Limit Aggregation Time Unit；
* 修复 generic 未设置且存在 entity group ids 时的查询问题；
* 修复实体数据查询，使用 max 替换 bool_or；
* 修复搜索；
* 修复实体选择中的文本搜索；
* 修复 Tenant User 查询中 generic 与 group 权限的组合；
* 从 tb-pe 镜像中移除 PostgreSQL；
* Remote integration API：连接错误时强制断开连接；
