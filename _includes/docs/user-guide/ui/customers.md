ThingsBoard中的**客户**代表独立的业务实体——个人或组织——购买或使用租户的设备及/或资产。客户也可表示租户组织内的部门或分支机构。

客户用户属于该客户，具有读取权限，可查看租户管理员分配的仪表板及其他实体。

在ThingsBoard社区版中，客户用户无法创建自己的客户、用户或子客户。

{% capture difference %}
**重要：**
<br>
在**ThingsBoard专业版**中，客户用户可创建其他客户、用户和子客户。
要体验此功能，请使用[ThingsBoard Cloud](https://{{hostName}}/signup)服务。
也可通过[安装指南](/docs/user-guide/install/pe/installation-options/)本地安装ThingsBoard。
{% endcapture %}

## 客户详情

点击客户会打开详情窗口，可查看并管理与该客户相关的全部内容。

{% include images-gallery.html imageCollection="customer-details-page" %}

<b><font size="3">Copy customer ID</font></b>   
Allows you to quickly retrieve the customer’s unique UUID. Click Copy customer Id to copy it to your clipboard. This ID is used in API calls, integrations, and automation scripts.

<b><font size="3">Attributes</font></b>

This tab displays client, server, and shared [attributes](/docs/{{docsPrefix}}user-guide/attributes/){:target="_blank"} associated with the customer. These are static or semi-static key-value pairs, such as contact information, region, account parameters, or custom metadata.

<b><font size="3">Latest telemetry</font></b>

Shows the [latest telemetry](/docs/{{docsPrefix}}user-guide/telemetry/){:target="_blank"} values linked to the customer. Telemetry can be generated by customer-related devices, services, or added manually for analytics and modeling purposes.
- **添加遥测**：点击「**+**」图标，定义键、值类型和值。
- **删除遥测**：点击垃圾桶图标，选择删除模式（全部数据、最新值、除最新外的全部或按时间范围），并确认操作。

<b><font size="3">计算字段</font></b>   
显示根据现有属性或遥测通过公式计算出的字段值。用于在客户层面派生更多业务指标。更多说明请参阅[此处](/docs/{{docsPrefix}}user-guide/calculated-fields/){:target="_blank"}。

<b><font size="3">告警规则</font></b>   
包含为客户配置的告警规则，定义如何根据客户级数据或关联资产/设备生成告警。更多配置说明请参阅[此处](/docs/{{docsPrefix}}user-guide/alarm-rules/){:target="_blank"}。

<b><font size="3">告警</font></b>  
显示与客户相关的全部当前及历史[告警](/docs/{{docsPrefix}}user-guide/alarms/){:target="_blank"}。便于跟踪影响客户或其基础设施的操作问题、警告和关键事件。

<b><font size="3">事件</font></b>   
显示与客户相关的系统事件——日志、警告、错误及生命周期活动。用于诊断和监控客户相关操作。

<b><font size="3">关系</font></b>   
显示客户与其他实体（如资产、设备、仪表板或规则链）之间的有向[关系](/docs/{{docsPrefix}}user-guide/entities-and-relations/#relations){:target="_blank"}。提供客户在系统中的结构概览。

<b><font size="3">审计日志</font></b>   
提供与客户相关的[用户操作记录](/docs/{{docsPrefix}}user-guide/audit-log/){:target="_blank"}——创建、更新、配置变更和删除。用于安全审计和变更跟踪。

<b><font size="3">版本控制</font></b>   
支持使用基于Git的[版本控制](/docs/{{docsPrefix}}user-guide/version-control/){:target="_blank"}服务导出和恢复客户相关实体。用于备份、协作工作流和配置版本管理。
