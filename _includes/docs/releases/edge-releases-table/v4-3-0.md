## v4.3.0 (2026年1月21日)

**主要**版本，包含 [TB CE v4.3.0](/docs/releases/releases-table/v4-3-x/){: target="_blank"} 的全部内容：

**改进**

* [#13998](https://github.com/thingsboard/thingsboard/pull/13998){: target="_blank"} **AI 模型同步**：新增 AI 模型自动同步至 Edge 实例以实现本地 AI 处理能力，由 [@jekka001](https://github.com/jekka001){: target="_blank"} 完成；
* [#14352](https://github.com/thingsboard/thingsboard/pull/14352){: target="_blank"} **Edge 用户与凭证同步**：新增 User 实体和 UserCredentials 从 Edge 同步至 Cloud 的支持，实现集中式用户管理，由 [@volodymyr-babak](https://github.com/volodymyr-babak){: target="_blank"} 完成；
* [#14447](https://github.com/thingsboard/thingsboard/pull/14447){: target="_blank"} **Edge 实体删除同步**：修改 edge-to-cloud 同步逻辑，传播实际实体删除（资产、设备、仪表板、实体视图）而非仅取消分配，由 [@MazurenkoNick](https://github.com/MazurenkoNick){: target="_blank"} 完成；
* [#14603](https://github.com/thingsboard/thingsboard/pull/14603){: target="_blank"} **Edge Events 优化**：在下行消息管道中为 Edge Events 增加合并与去重过滤功能，通过合并属性更新并移除完全重复项减少发送至 edge 设备的事件数量，由 [@volodymyr-babak](https://github.com/volodymyr-babak){: target="_blank"} 完成；
* [#209](https://github.com/thingsboard/thingsboard-edge/pull/209){: target="_blank"} **下行重复合并**：实现下行消息的合并与去重过滤功能，优化 Edge 通信，由 [@volodymyr-babak](https://github.com/volodymyr-babak){: target="_blank"} 完成；
* [#208](https://github.com/thingsboard/thingsboard-edge/pull/208){: target="_blank"} **重构 BaseCloudManagerService 及其实现**，由 [@MazurenkoNick](https://github.com/MazurenkoNick){: target="_blank"} 完成；
* [#14489](https://github.com/thingsboard/thingsboard/pull/14489){: target="_blank"} **Edge 更新去重**：在 edge 处理器中引入 generateUniqueNameIfDuplicateExists 功能，减少重复实体更新，由 [@MazurenkoNick](https://github.com/MazurenkoNick){: target="_blank"} 完成；

**Bug 修复**

* [#13843](https://github.com/thingsboard/thingsboard/pull/13843){: target="_blank"} **改进 Edge 会话清理**，防止因网络不稳定和 Kafka 繁忙超时导致的资源泄漏和消息积压，由 [@bcblr1993](https://github.com/bcblr1993){: target="_blank"} 完成。
