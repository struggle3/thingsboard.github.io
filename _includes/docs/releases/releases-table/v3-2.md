### ThingsBoard CE v3.2 (2020年12月1日)

本版本旨在简化设备配置与连接以及告警配置。
同时增加租户 API 使用量追踪功能。

**主要改进**

 * [租户配置](/docs/user-guide/tenant-profiles/)：管理 API 与速率限制；
 * [设备配置](/docs/user-guide/device-profiles/)：配置默认规则链与队列、设置传输配置、定义[告警规则](/docs/user-guide/device-profiles/#alarm-rules)；
 * 新增自定义 [MQTT 主题](/docs/user-guide/device-profiles/#mqtt-device-topic-filters) 和基础 [MQTT 凭证](/docs/user-guide/basic-mqtt/) 作为 access token 的替代；
 * 为 MQTT 传输增加使用 [Protocol Buffers](/docs/user-guide/device-profiles/#mqtt-device-payload) 的自定义设备 payload  schema 支持；
 * [设备配置](/docs/user-guide/device-provisioning/) 现可通过设备配置访问；
 * [SMS 提供者](/docs/user-guide/ui/sms-provider-settings) 和 [Send SMS](/docs/user-guide/rule-engine-2-0/external-nodes/#send-sms-node) 规则节点；
 * [OAuth2](/docs/user-guide/oauth-2-support/) 设置的 UI。

**次要改进**

 * 新增 [API 使用](/docs/user-guide/tenant-profiles/#api-usage-dashboard) 仪表板；
 * 为遥测控制器新增 orderBy 请求参数；
 * 在 TbSendRPCRequestNode 的 enqueueForTellNext 中增加 queueName；
 * 防止不同规则链间的循环引用；
 * 新增巴西葡萄牙语；
 * 改进相机和告警部件、图例排序；
 * 在 multiple attributes input 部件中增加 min/max 值支持；
 * UI 性能改进；

 **Bug 修复**

 * 即使禁用 fit bounds marker，地图部件默认也覆盖所有标记以适应边界；
