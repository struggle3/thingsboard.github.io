### ThingsBoard CE v3.4（2022年7月19日）

包含以下功能与 Bug 修复的主要版本：

**主要改进**

* 核心与规则引擎：
  * [#6534](https://github.com/thingsboard/thingsboard/pull/6534) 通过租户配置配置规则引擎队列，参见文档[此处](/docs/user-guide/rule-engine-2-5/queues/)；
  * [#6070](https://github.com/thingsboard/thingsboard/issues/6070) 2FA 支持，参见文档[此处](/docs/user-guide/two-factor-authentication/)；
  * [#6759](https://github.com/thingsboard/thingsboard/pull/6759) 版本控制（Git 集成），参见文档[此处](/docs/user-guide/version-control/)；
  * [#6893](https://github.com/thingsboard/thingsboard/pull/6893) 将 JS-Executor 微服务重构为 TypeScript；
* UI：
  * [#6334](https://github.com/thingsboard/thingsboard/issues/6334) 时序部件中最新值支持；
  * [#6545](https://github.com/thingsboard/thingsboard/pull/6545) 用 Angular 组件替换自动生成的高级部件设置 JSON 表单；
* Edge：
  * [#6781](https://github.com/thingsboard/thingsboard/pull/6781) Edge OTA 支持；
  * [#6852](https://github.com/thingsboard/thingsboard/pull/6852) 队列 API 支持；
