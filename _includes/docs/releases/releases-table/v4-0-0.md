**Breaking changes**

* [#11937](https://github.com/thingsboard/thingsboard/pull/11937) ❌ 移除除 Kafka 外的所有队列类型  
  → **影响**：之前使用其他队列类型（如 RabbitMQ）的系统现必须迁移至 Kafka。请确保基础设施和配置已相应更新。

* [#12859](https://github.com/thingsboard/thingsboard/pull/12859) 🧹 从 UI 移除 `flex-layout` 库  
  → **影响**：依赖 `flex-layout` 的自定义 UI 组件或扩展将失效。请用 Angular 原生布局功能或现代 CSS 技术替代。
