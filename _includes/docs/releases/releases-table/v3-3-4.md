### ThingsBoard CE v3.3.4（2022年3月11日）

包含以下改进与 Bug 修复的次要版本：

**改进**

* 核心：
  * [#6024](https://github.com/thingsboard/thingsboard/issues/6034) ThingsBoard Edge 社区版支持；
  * [#6056](https://github.com/thingsboard/thingsboard/issues/6056) DefaultTbApiUsageStateService 中 PartitionChangeEvent 的处理为同步；
  * [#6139](https://github.com/thingsboard/thingsboard/pull/6139) 校验器重构，移至独立类；
  * [#6146](https://github.com/thingsboard/thingsboard/issues/6146) Edge - 从云中删除时设备配置不会从 edge 中移除；
  * 针对数千租户环境的启动序列性能改进；
  * 事件实体插入性能改进，实现批量插入；
  * 设备状态服务改进与竞态条件修复；
* UI：
  * [#5984](https://github.com/thingsboard/thingsboard/pull/5984) 更新简体中文本地化；
  * [#6063](https://github.com/thingsboard/thingsboard/pull/6063) 为地图部件添加圆形支持及其他改进；
  * 更新「gps 地理围栏事件」节点默认配置，更新规则节点配置 UI；
* 传输：
  * 抑制频繁日志，修复 IP 速率限制时的连接统计；
  * LwM2M：
    * [#6032](https://github.com/thingsboard/thingsboard/issues/6032) lwm2mClients 连接模式的测试覆盖；
    * [#6026](https://github.com/thingsboard/thingsboard/issues/6026) LwM2mClient 不再可序列化；
    * [#6200](https://github.com/thingsboard/thingsboard/issues/6200) 处理来自服务器的 LwM2M 发送请求；

**Bug 修复**

* 核心与规则引擎：
  * [#5991](https://github.com/thingsboard/thingsboard/issues/5991) 可删除被 OTA 更新包引用的设备配置；
  * [#6122](https://github.com/thingsboard/thingsboard/issues/6122) 支持 TbMsgMetaData 中的 null 值；
  * [#6132](https://github.com/thingsboard/thingsboard/issues/6132) 创建告警规则节点 - Propagate To Tenant 不工作；
  * [#6174](https://github.com/thingsboard/thingsboard/pull/6174) 为兼容 3.3.2 自动转换规则链元数据；
  * [#5996](https://github.com/thingsboard/thingsboard/issues/5996) 批量导入期间创建的 LwM2M 设备配置问题；
  * [#6204](https://github.com/thingsboard/thingsboard/pull/6204) 客户告警权限检查器修复；
  * [#6212](https://github.com/thingsboard/thingsboard/issues/6212) 修复 API 请求中未解析的动态值；
  * 更新规则节点配置 UI：修复「计算增量」规则节点「Period key value」字段的必填消息；
* UI：
  * [#5975](https://github.com/thingsboard/thingsboard/issues/5975) 部件开发插件加载顺序；
  * [#6022](https://github.com/thingsboard/thingsboard/issues/6022) 告警表格部件在「允许清除告警」禁用时仍允许清除告警；
  * [#6015](https://github.com/thingsboard/thingsboard/issues/6015) 改进地图控制按钮提示，修复编辑时标记/多边形更新错误；
  * [#5697](https://github.com/thingsboard/thingsboard/issues/5697) Base64 值解码功能；
  * [#6092](https://github.com/thingsboard/thingsboard/issues/6092) 图像地图使用空图像初始化时不加载图像更新；
  * [#6123](https://github.com/thingsboard/thingsboard/pull/6123) 修复设备管理表格的编辑操作；
  * [#6127](https://github.com/thingsboard/thingsboard/issues/6127) 编辑固件对话框未使用默认 OTA 包类型；
  * 地图部件 - 修复编辑模式下的自动缩放；
  * 修复行程动画部件，数据获取后移除加载区域；
  * 修复时间窗口面板表单校验，聚合非 none 时禁用聚合限制检查；
* 传输：
  * [#6025](https://github.com/thingsboard/thingsboard/issues/6025) SNMP：因 SNMP 传输初始化错误导致应用无法启动；
  * [#6048](https://github.com/thingsboard/thingsboard/issues/6048) LwM2M：休眠后发送共享属性；
  * [#6050](https://github.com/thingsboard/thingsboard/issues/6050) LwM2M：修复 read/observe「dataRead」对象 19；
  * [#6054](https://github.com/thingsboard/thingsboard/issues/6054) LwM2M：修复「No value present」；
  * [#6058](https://github.com/thingsboard/thingsboard/pull/6058) LwM2M：改进集成测试稳定性；
  * [#6118](https://github.com/thingsboard/thingsboard/issues/6118) LwM2M：使 LwM2MBootstrapConfigStoreTaskProvider 中 getTasks 线程安全；
