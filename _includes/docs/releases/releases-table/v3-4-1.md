### ThingsBoard CE v3.4.1（2022年8月18日）

包含以下改进与 Bug 修复的**次要**版本：

* 核心：
  * 改进[设备状态服务](https://thingsboard.io/docs/user-guide/device-connectivity-status/)的性能和稳定性；
  * [#6983](https://github.com/thingsboard/thingsboard/pull/6983) 修复因 Spring 循环依赖导致的启动失败；
  * [#6923](https://github.com/thingsboard/thingsboard/pull/6923) 用仓库内实现替换已弃用的 StringUtils 用法；
  * [#6959](https://github.com/thingsboard/thingsboard/pull/6959) 修复 EntityDataAdapter 中将以「0」开头的字符串值自动转换为 double；
  * [#6972](https://github.com/thingsboard/thingsboard/pull/6972) 修复至 3.4.0 的升级脚本；
  * [#7026](https://github.com/thingsboard/thingsboard/pull/7026) 修复 2FA 中的序列化；
  * [#7041](https://github.com/thingsboard/thingsboard/pull/7041) 修复「inactivityTimeout」属性的更新或移除；
* UI：
  * [#7025](https://github.com/thingsboard/thingsboard/pull/7025) 在规则节点调试事件表中添加新列和复制按钮；
  * [#6980](https://github.com/thingsboard/thingsboard/pull/6980) 在用户详情中添加关系标签；
  * [#6979](https://github.com/thingsboard/thingsboard/pull/6979) 改进租户配置中的速率限制视图；
  * [#6978](https://github.com/thingsboard/thingsboard/pull/6978) 改进部件设置中的移动视图；
  * [#6987](https://github.com/thingsboard/thingsboard/pull/6987) 修复使用 2FA 登录后重定向到上一链接；
  * [#7011](https://github.com/thingsboard/thingsboard/pull/7011) 修复地图部件的自定义标记大小；
  * [#7012](https://github.com/thingsboard/thingsboard/pull/7012) 更新 leaflet 版本至 1.8；
  * [#7055](https://github.com/thingsboard/thingsboard/pull/7055) 修复 Flot 部件中的预定义阈值；
  * [#7073](https://github.com/thingsboard/thingsboard/pull/7073) 修复日语语言本地化名称错误；
  * [#7086](https://github.com/thingsboard/thingsboard/pull/7086) 修复代码重复调用 Bug；
  * [#7097](https://github.com/thingsboard/thingsboard/pull/7097) 2FA 中的小修复；
  * [#7105](https://github.com/thingsboard/thingsboard/pull/7105) 修复圆形定位 Bug；
  * [#7108](https://github.com/thingsboard/thingsboard/pull/7108) 修复三次点击后的表格移位；
* 传输：
  * [#6967](https://github.com/thingsboard/thingsboard/pull/6967) 修复 Netty MQTT 客户端 ping/pong 逻辑；
  * [#0bc5be4](https://github.com/thingsboard/thingsboard/commit/0bc5be477c585af7953d44824bfcd74a3c4ee50c) 对无观察的会话的 Coap 设备配置更新修复；
* Edge：
  * [#6953](https://github.com/thingsboard/thingsboard/pull/6953) 从 edge 取消分配规则链时检查缺失的 edge 规则链；
  * [#7044](https://github.com/thingsboard/thingsboard/pull/7044) 设备/设备配置中的固件 ID 未从云同步到 edge；
  * [#7095](https://github.com/thingsboard/thingsboard/pull/7095) 同步完成后开始常规 edge 事件处理；
