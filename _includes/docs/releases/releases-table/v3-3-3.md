### ThingsBoard CE v3.3.3（2022年1月27日）

包含以下改进与 Bug 修复的次要版本：

**改进**

* 核心：
  * 告警查询性能改进；
  * 多根关系查询；
  * 支持配置 SQL 请求中的默认 null 排序；
  * 获取 TB 应用版本的 REST API；
  * 不持久化空统计以减少事件表大小和磁盘 IOPS；
  * thingsboard.yml 注释的 minor 改进；
  * 为密码策略添加空格校验；
  * 通知 IoT 网关设备的删除或重命名；
  * [#5200](https://github.com/thingsboard/thingsboard/pull/5200) 仪表板 / 告警规则过滤器的「IN」和「NOT IN」条件；
  * [#5749](https://github.com/thingsboard/thingsboard/pull/5749) 队列工厂；
  * [#5760](https://github.com/thingsboard/thingsboard/pull/5760) SQL 和 TS 批量线程数 3 以改进哈希分布；
  * [#5814](https://github.com/thingsboard/thingsboard/pull/5814) 使用过滤器清除事件的 API；
* 规则引擎：
  * 支持多输出的嵌套规则链；
  * [#5569](https://github.com/thingsboard/thingsboard/pull/5569) 保存时序数据时不更新最新值，混合 DB 设置下有助于性能改进；
  * 降低带内存缓存版本的 CPU 开销；
  * 通过环境变量配置内存缓存；
  * [#5843](https://github.com/thingsboard/thingsboard/pull/5843) 设备 actor 会话非活动性能与内存占用优化；
  * [#5751](https://github.com/thingsboard/thingsboard/pull/5751) 设备和正确缓存清除的事务性删除；
  * [#5550](https://github.com/thingsboard/thingsboard/pull/5550) 升级富化属性规则节点；
  * 其他性能改进：不可变结构、预定义 protobuf 对象等；
  * [#5865](https://github.com/thingsboard/thingsboard/pull/5865) 添加对 3.3.0 edge 版本规则链的支持；
  * [#5762](https://github.com/thingsboard/thingsboard/pull/5762) MQTT 规则节点中「clientId」参数的后缀；
  * [#5821](https://github.com/thingsboard/thingsboard/pull/5821)「保存时序」规则节点添加 ignoreMetadataTs；
  * [#5889](https://github.com/thingsboard/thingsboard/pull/5889) 减少会话超时的计划消息数量；
  * [#5921](https://github.com/thingsboard/thingsboard/pull/5921) 向无关系的客户或租户传播告警；
  * [#5926](https://github.com/thingsboard/thingsboard/pull/5926) 在「创建告警」规则节点中使用消息时间戳作为告警开始时间戳；
  * [#5687](https://github.com/thingsboard/thingsboard/pull/5687) 自相交多边形、带孔多边形、多多边形支持；
* UI：
  * 迁移至 Angular 12；
  * 嵌入不同仪表板状态的部件；
  * 在 markdown 部件中嵌入仪表板状态；
  * [#5942](https://github.com/thingsboard/thingsboard/pull/5942) 添加生成自定义部件数据结构的脚本；
  * [#5797](https://github.com/thingsboard/thingsboard/pull/5797) 实体详情的独立页面；
  * [#5770](https://github.com/thingsboard/thingsboard/pull/5770) 地图部件中标记和多边形的编辑器；
  * [#5757](https://github.com/thingsboard/thingsboard/pull/5757) 多属性部件改进；
  * [#5629](https://github.com/thingsboard/thingsboard/pull/5629) 显示持久化 RPC 调用的部件；
  * [#5856](https://github.com/thingsboard/thingsboard/pull/5856) 实体页面的持久化链接；
  * 在规则链编辑器中选择区域创建嵌套规则链；
  * 为地图部件添加提示偏移设置；
  * [#5655](https://github.com/thingsboard/thingsboard/pull/5655) 移动视图中隐藏页面大小选项；
  * [#5772](https://github.com/thingsboard/thingsboard/pull/5772) 仅在时序和最新部件中显示图例设置；
  * [#5795](https://github.com/thingsboard/thingsboard/pull/5795) 启用后处理函数时禁用列排序；
  * [#5876](https://github.com/thingsboard/thingsboard/pull/5876) 图像地图调整大小正确计算中心位置；
  * [#5882](https://github.com/thingsboard/thingsboard/pull/5882) 新地图部件设置：「禁用缩放控制」；
  * [#5910](https://github.com/thingsboard/thingsboard/pull/5910) 添加定义 showTitleIcon 的附加条件；
* 传输：
  * LwM2M：
    * 支持定义网络配置；
    * [#5930](https://github.com/thingsboard/thingsboard/pull/5930) 更新 Eclipse Leshan 版本至 2.0.0-M5；
    * 支持 Base64 格式定义 RPK 和 X509 模式下的客户端密钥；
    * 引入新命令支持：Read-Composite、Write-Composite，多实例资源的读与写；
    * 引入新内容格式支持：SenML JSON、SenML CBOR；
    * 通过设备配置改进 Bootstrap 行为配置；
    * Bootstrap 服务器现支持：Read、Discover、Write、Delete 命令；
  * CoAP：
    * [#5930](https://github.com/thingsboard/thingsboard/pull/5930) 更新 Californium 版本至 3.0.0；
  * SNMP：
    * 为 SNMP 传输添加 Redis 配置；
  * MQTT：
    * [5875] MQTT 的 IP 速率限制；
* 安全：
  * 更新 log4j-core、log4j-api 和 log4j-to-slf4j 版本；
  * 支持限制告警查询调用次数；
  * [#5823](https://github.com/thingsboard/thingsboard/pull/5823) 为规则节点名称添加 NO XSS 校验；
* 构建脚本：
  * 支持 linux/arm64 docker 容器；
  * SQL 测试现于真实 PostgreSQL 而非 HSQL 上运行；
  * 更新 grpc 和 netty 版本以正确处理原生 windows ssl 库；
