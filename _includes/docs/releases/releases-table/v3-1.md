### ThingsBoard CE v3.1 (2020年8月12日)

小版本更新，包含以下改进与 Bug 修复。

**主要特性**

 * 对实体字段、属性和最新遥测的过滤；
 * 告警部件改进；
 * PostgreSQL 中 inset 的性能改进；
 * 支持将最新值存储在 SQL 而非 NoSQL；

**附加特性**

 * UI：
   * 用于部件开发的外部 Angular 模块；
   * 实体批量导入中支持 .txt 扩展名文件；
   * Flot：在 datakeys 标签中添加属性支持；
   * Maps 集群模式优化；
   * 在图片地图上编辑多边形；
   * 新增别名实体类型：当前用户和当前用户所有者（租户或客户）；
 * 规则引擎：
   * 改进失败和超时消息的日志记录；
   * Azure IoT Hub 规则节点；
   * 从规则节点链接打开规则链；
   * Clear alarm 节点现接受告警 ID 作为发起者；
   * 记录确认消息耗时；
   * 在规则节点中显示排序的元数据键；
 * REST API：支持将设备移至另一租户；
 * 为 AWS SQS 启用默认凭证提供者链；
 * 增加 MQTT payload 错误日志记录；
 * 增加 Confluent cloud 支持；

**Bug 修复**

 * UI：
   * 修复图片地图部件上显示多边形；
   * 修复无分页时的页面链接，若干小修复；
   * 修复布尔输入部件；
   * 修复 Web Camera 输入部件；
