## 概述

Tinker Board S 是一款单板计算机（SBC），面向 DIY 爱好者与创客，具有更高耐用度、稳定性和整体体验。  
板载 16 GB eMMC 存储提升性能与稳定性，microSD 卡槽提供扩展空间。  
板载上电引脚便于创客实现创意。  
低压输入检测可避免电源问题，在使用非合格电源时保证系统稳定。  
增强 I2S 引脚支持从机模式，软件 API 优化以提升兼容性。
