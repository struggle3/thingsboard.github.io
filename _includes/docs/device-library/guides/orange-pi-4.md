## 概述

Orange Pi 4 是一款高性能单板计算机（SBC），采用六核瑞芯微 RK3399 ARM Cortex-A72/A53 CPU、4 GB RAM 与千兆以太网。
配备 Wi-Fi、Bluetooth，支持 4K 超高清视频播放。
提供 USB 3.0、两个 USB 2.0 及 HDMI 2.0a 接口。
