## 概述

华硕 Tinker Board 2S 是一款高性能、功能丰富的单板计算机。  
搭载瑞芯微 RK3399 处理器、2 GB RAM 及 Mali-T860MP4 GPU。  
配备千兆以太网、Wi-Fi、Bluetooth、USB，便于连接互联网或其他设备。  
提供 PCIe 插槽，可扩展 SATA 控制器、网卡等硬件。
