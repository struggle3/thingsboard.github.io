## 概述

DragonBoard™ 410c 是首款基于高通® APQ8016e 应用处理器的开发板。
信用卡尺寸，集成高性能处理器、Wi-Fi、Bluetooth、GPS。
基于 64 位 Qualcomm APQ8016e，专为快速软件开发、教育与原型设计设计，符合 96Boards 消费版规范。
适合嵌入式计算与物联网（IoT）产品，包括机器人、摄像头、医疗设备、自动售货机、智能建筑、数字标牌、游戏机等。
