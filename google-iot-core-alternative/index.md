        <main>
            <div class="background">
				<div class="bottom-features1"></div><div class="bottom-features2"></div><div class="small11"></div><div class="small12"></div><div class="bottom-features3"></div><div class="small13"></div><div class="small14"></div><div class="small15"></div>
			</div>
            <h3>核心概念</h3>
            <p>请参阅以下 IoT Core 核心概念与 ThingsBoard 功能的对应文档映射：</p>
            <div class="row cards">
                <div class="col-lg-6">
					<div class="block">
						<div>
							<a class="title" href="/docs/pe/user-guide/ui/devices/">设备</a>
							<p>ThingsBoard 支持类似 Google IoT Core 的设备<a href="/docs/pe/user-guide/ui/devices/">配置与管理</a>。
                            然而，IoT 应用不仅限于设备。ThingsBoard 还支持其他<a href="/docs/pe/user-guide/entities-and-relations/">实体及关系</a>。
                            关系模型支持高级用例和业务逻辑。例如，您可配置资产、设备、客户等之间的关系。</p>
						</div>
					</div>
				</div>
                <div class="col-lg-6">
					<div class="block">
						<div>
							<a class="title" href="/docs/pe/user-guide/telemetry/">遥测</a>
							<p>遥测是从设备发送到云端的事件数据，例如环境测量数据。
                            ThingsBoard 支持类似 IoT Core 的从设备采集数据。ThingsBoard 还支持平台内数据处理（包括验证、告警等）和存储。
                            详见 <a href="/docs/pe/user-guide/rule-engine-2-0/re-getting-started/">规则引擎</a>。
                            您还可将数据转发到外部系统（如 PubSub），并复用现有数据处理流程。</p>
						</div>
					</div>
				</div>
                <div class="col-lg-6">
					<div class="block">
						<div>
							<a class="title" href="/docs/pe/user-guide/device-connectivity-status/">设备状态</a>
							<p>ThingsBoard 监控设备<a href="/docs/pe/user-guide/device-connectivity-status/">连接状态</a>，
                            并允许设备通过客户端<a href="/docs/pe/user-guide/attributes/#client-side-attributes">属性</a>功能上传其状态。
                            您可配置平台在设备离线或状态变更时触发告警。
                            ThingsBoard 还支持通过空中升级 <a href="/docs/pe/user-guide/ota-updates/">固件与软件</a>并监控更新过程。
                            </p>
						</div>
					</div>
				</div>
                <div class="col-lg-6">
					<div class="block">
						<div>
							<a class="title" href="/docs/pe/user-guide/attributes/">设备配置</a>
							<p>ThingsBoard 的设备配置能力与 Google IoT Core 相似。
                            参见设备<a href="/docs/pe/user-guide/attributes/">属性</a>文档。
                            高级用户可能会注意到以下重要差异：
                            ThingsBoard 允许分别推送每个属性（配置）更新；
                            可通过仪表板、管理 UI、REST API 调用或脚本修改配置属性；
                            属性通过 JSON 或 protobuf 格式发送到设备。</p>
						</div>
					</div>
				</div>
                <div class="col-lg-6">
					<div class="block">
						<div>
							<a class="title" href="/docs/pe/user-guide/device-provisioning/">设备注册表与设备管理器</a>
							<p>ThingsBoard 提供灵活的注册、监控和配置设备接口：
                            仪表板、管理 Web UI、REST API、<a href="/docs/pe/user-guide/bulk-provisioning/">CSV 上传</a>和自动<a href="/docs/pe/user-guide/device-provisioning/">配置</a>。
                            平台在添加、分组和控制设备方面提供更高灵活性。
                            您可在不同租户下注册设备，或将设备分配给不同客户。
                            最终用户可在<a href="/docs/pe/user-guide/self-registration/">自助注册</a>过程中<a href="/docs/pe/user-guide/claiming-devices/">认领设备</a>。
                            ThingsBoard 具备支持复杂用例所需的一切内置工具。</p>
						</div>
					</div>
				</div>
                <div class="col-lg-6">
					<div class="block">
						<div>
							<a class="title" href="/docs/pe/getting-started-guides/connectivity/">通过 MQTT 和 HTTP 发布</a>
							<p>IoT Core 的核心是 MQTT broker，用于设备与云端之间的数据交换。
                            ThingsBoard 同样充当 MQTT broker，但存在若干差异。
                            在 ThingsBoard 中，您不受静态主题名称模式限制，可根据需求定义任意通配符主题过滤器。
                            平台接受 JSON 或 protobuf 有效负载。
                            ThingsBoard 支持<a href="/docs/pe/user-guide/access-token/">访问令牌</a>、
                            <a href="/docs/pe/user-guide/basic-mqtt/">基本 MQTT 凭据</a>或
                            <a href="/docs/pe/user-guide/certificates/">X.509 证书</a>。

                            除 MQTT 和 HTTP 外，设备还可使用 CoAP、LwM2M、SNMP 等协议与平台原生通信。
                            您还可使用我们的<a href="/docs/iot-gateway/what-is-iot-gateway/">IoT Gateway</a>，通过 BLE、CAN、Modbus、OPC-UA、BACnet、ODBC 等集成连接至传统及第三方系统的设备。

                            ThingsBoard 还内置 SigFox、LoRaWAN、NB IoT 等外部系统集成。
                            可在此查看所有可用集成<a href="/docs/user-guide/integrations/">列表</a>。</p>
						</div>
					</div>
				</div>
                <div class="col-lg-6">
					<div class="block">
						<div>
							<a class="title" href="/docs/pe/user-guide/rpc/">向设备发送和接收命令</a>
							<p>您可使用 ThingsBoard <a href="/docs/pe/user-guide/rpc/">RPC</a> 功能向设备发送和接收命令。
                            命令可持久化或非持久化，单向或双向，您可为不同命令类型配置重试和失败策略。
                            命令可由用户通过仪表板、REST API 或在平台接收事件后触发。</p>
						</div>
					</div>
				</div>
            </div>
